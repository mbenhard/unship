# Terminology

- **Exploration** — one temporary comparison task, containing one or more groups.
- **Group** — a named target such as a hero or pricing card, containing options.
- **Option** — one candidate direction.
- **Canvas** — simultaneous comparison on a zoomable surface.
- **Arrangement** — the agent-selected presentation: stack or grid.
- **Frame** — the Canvas position of one original live option.
- **Keep** — copy the selected option and group. The agent interprets it using the user’s instructions; copying alone does not request cleanup.
